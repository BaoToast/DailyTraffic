全日交通量及車種組成 — 完整專案 v20.28
=================================================

■ v20.28：補齊「在別台電腦也重建得出來」的發布工程

  由外部複核（GPT）指出並修好的一個實質缺口：v20.27 以前的交付包
  **排除了 github-pages 這個資料夾**，而那正是重建 GitHub Pages 網站
  所需要的 vite 設定（index.html／vite.config.ts／src/main.tsx）。
  後果是交付包在別台電腦解開之後，npm run build:pages 與 npm run e2e
  直接失敗——網站根本重建不出來，而當時沒有任何檢查會發現。

  本版補回建置來源與 build/sites-vite-plugin.ts；新增 scripts/run-vinext.mjs
  讓 Windows 也能直接執行；npm run e2e 改成先產生測試樣本、再建置、
  最後才跑三組瀏覽器測試，不必人工附帶測資。

  並擴充 tests/dependency-manifest.test.mjs，現在會攔截：建置入口遺失、
  建置外掛遺失、.github/workflows/ci.yml 與 .gitignore、.nojekyll 遺失、
  以及 e2e 沒有依「產生樣本 → 建置 → 瀏覽器測試」的順序執行。
  **這一支測試如果早點存在，上面那個缺口不會活到 v20.27。**

  **沒有變更任何計算規則**：交通量、PCU、尖峰、車種組成、駛入／駛出
  全部未動。已逐檔比對確認 app/DashboardClient.tsx 的差異只有兩行
  手冊連結的版號。

  同步調整根目錄 index.html 的 meta description，移除「GitHub Pages 備用版」
  字樣，使搜尋與分享摘要符合目前正式維護定位；只影響網頁描述，不影響
  畫面功能、資料或任何計算。

■ v20.27：結論草稿存好的「條件範本」現在會跟著備份走

  使用者在結論草稿產生器存的條件範本，之前只存在該台電腦的瀏覽器裡，
  匯出的備份檔沒有收——換一台電腦匯入之後範本一個都不剩，
  而畫面只會顯示匯入成功，不會提醒少了什麼。
  本版把 conclusionTemplates 納入 exportBackup()，還原時寫回去。

  還原是**合併**不是覆蓋：同名範本以備份檔為準，本機其他名字的範本保留；
  舊版備份檔（沒有這個欄位）匯入時不會把本機既有範本清掉。
  升版前匯出的舊備份檔裡本來就沒有範本，請使用者重新匯出一份。

  新增 tests/backup-completeness.test.mjs（3 項），以清單比對釘住
  「匯出時有收、匯入時有還原、舊備份不得清空」。

■ v20.26：結論草稿的「時段」說明講清楚了

  「時段」至少要留一個，這一點沒有變——這一區每一項數字都是寫在
  某一個時段底下的，全部取消就一行都寫不出來。但常見的需求是
  「我只要全日的數字」，那不是取消全部，**是只勾「全日」**。
  畫面上的說明原本沒告訴您該怎麼做，本版補上。
  只改說明文字，沒有動任何計算或勾選邏輯。

  手冊裡另外用一張表把三套系統「不勾」的意思一次講清楚
  （本系統不允許全不勾；路口轉向＝不敘述尖峰；交通服務水準＝全部都寫）。

■ v20.25：全日車輛總數不正確、駛入與駛出總數不一致

  早期版本匯入時把四大類車輛數四捨五入成整數存起來，而逐時段的轉向明細
  保留了原始小數（0.36＋11＋1＝12.36 對 12）。一天 24 小時、一個路口
  4 條支線，零頭累積起來就是好幾輛的誤差；「駛入」視角又把兩者的差額
  補進「未指定駛入路口」，而且只補多出來的、不扣少掉的，於是駛入的合計
  比駛出多。改為讀取時優先採用轉向明細，只有差距超過 1 輛才沿用欄位。
  **不需要重新匯入。** 以使用者的真實備份驗證：75 組路口資料、
  涵蓋所有季度，駛入與駛出合計全部相等。

■ v20.24：切到「駛入路口」時調查點欄位仍寫著（駛出）

  每一列只在「並列」模式下才記住自己的視角，單一視角時退回去沿用
  上方工具列的視角來標示。已改為每一列都帶著自己的視角。不影響數字。

如何更新
-----------------------------------------------------------------
把本壓縮檔內的所有檔案，覆蓋到 GitHub repository
（https://github.com/baotoast/DailyTraffic）的根目錄，然後 commit + push。

**請先手動刪除舊版手冊**：manuals 資料夾裡所有不是 v20.28 的
Traffic_Analysis_Beginner_Guide_*.pdf 與 .docx。

本版起 repository 同時存放原始碼與建置後的網站，並附自動測試
（.github/workflows/ci.yml，只測試不發布）。

部署完成後請確認：畫面右下角顯示「v20.28」，
同一個路口切換「駛入」與「駛出」視角時合計相同。
