全日交通量及車種組成 — GitHub Pages 更新包 v20.2
================================================

本次新增：上下午各 N 小時的部分時段調查格式分析（15 分鐘一格），
支援三叉、十字到七叉路口；尖峰小時改用連續 4 格＝1 小時的滾動視窗，
全日量為實際調查時段加總並加註說明。既有全日格式的計算完全不變。

更新步驟（與上次相同）
----------------------
1. 刪除 repository 根目錄的舊 assets 資料夾（整個刪掉），
   以及 manuals 內的 v20.1 手冊（PDF 與 Word）。
2. 把本壓縮檔內全部檔案放到 repository 根目錄
   （index.html、assets/、manuals/、README.md…）。
3. commit → push，約 1～3 分鐘後生效；畫面沒變請按 Ctrl+F5。
4. 確認：頁面右上角顯示「系統版本 v20.2」。

匯入七叉路口這類「一條支線一張工作表」的檔案後
------------------------------------------------
請務必到「路口幾何」確認各支線的角度。這類檔案的欄位是「往B、往C…」，
沒有左轉／直行／右轉，系統是依角度自動判定轉向再套用對應的 PCU 係數。
角度正確，PCU 才會正確；日後調整角度，所有分析會自動重算。
