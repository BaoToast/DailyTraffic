全日交通量及車種組成 — GitHub Pages 更新包 v20.4
================================================

本次修正
--------
1. 多岔路口（五叉以上）的「駛出路口X」各支線流量分配錯誤。
   舊版把一條支線的左轉全部算給單一個目的支線；七叉路口的 A 左轉可能
   同時通往 B、C、D，全部塞進同一條之後各支線的駛出量就不對（總計仍正確）。
   現在依原始檔記錄的實際目的地分配。以實測檔驗證，駛出各支線的上午尖峰
   為 422.4／414.3／628.5／56.2／184.5／1703.2／567.5，與原檔完全相同。
2. 部分時段提醒方塊文字溢出框線的版面問題。

名詞提醒
--------
「駛入路口X」＝依起點統計（從 X 開進路口的車）
「駛出路口X」＝依終點統計（最後開進 X 的車）
兩者總計必定相同，但各支線的分佈不同。與其他報表對數字時，
請先確認雙方用的是同一種視角。

更新步驟（與上次相同）
----------------------
1. 刪除 repository 根目錄的舊 assets 資料夾（整個刪掉），
   以及 manuals 內的 v20.3 手冊（PDF 與 Word）。
2. 把本壓縮檔內全部檔案放到 repository 根目錄。
3. commit → push，約 1～3 分鐘後生效；畫面沒變請按 Ctrl+F5。
4. 確認：頁面右上角顯示「系統版本 v20.4」。
